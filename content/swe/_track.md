@brief
- Loops still run **coding, system design and behavioral** rounds, weighted by level. Several 2026 guides say behavioral and design now carry about as much weight as coding at large companies.
- **AI-assisted coding rounds are spreading.** Google is piloting an approved AI assistant in coding rounds for junior and mid-level roles, plus a code comprehension round on existing code. Meta reportedly swapped one algorithm round for an AI-assisted round on a real codebase. They grade decomposition, verification and narration, not typing speed.
- It is not universal: CoderPad's 2026 data says about a third of hiring teams still ban AI, so practise both ways.
- System design shows up from mid-level upward. New grads usually get lighter prompts like a URL shortener or a rate limiter.
@tips
- **Think out loud.** Silence is the most common reason good candidates fail.
- **Clarify first:** inputs, edge cases, scale. Then brute force, then optimise, then test with an example.
- **Use numbers:** Big O, latency, requests per second.
- **Behavioral:** STAR, with a measurable result and what you would do differently.
- **Name the trade-off.** There is rarely one right answer, only a defended one.
